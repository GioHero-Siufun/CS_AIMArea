# CS2 基本功训练器

一个纯前端的 CS2 基本功练习网页，两个模块：

| 训练 | 内容 | 快捷键 |
|---|---|---|
| **左手 · 急停训练** | **第一人称 3D** 视角（指针锁定 + 鼠标视角，WASD 相对视角移动），冲向目标光柱圈后**反向按键急停**；切换到编辑工具时自动变为 2D 俯视 | W A S D 移动 · 空格跳跃 · 鼠标视角 · Esc 解锁 · F 下一目标 · 工具切换编辑 |
| **右手 · 瞄准训练** | 类 aim_botz 的 3D 打靶：指针锁定 + 视角瞄准，四种模式 | 左/右键射击 · Esc 解锁 · R 掷球 · 1–4 切换模式 · WASD 移动（可选） |

> 左手/右手训练共享鼠标灵敏度与 FOV（CS2 换算：角度 = 0.022 × 灵敏度 × 计数），任意一页调整都会同步。

### 急停计时规则（v2）

计时起点 = **按下刹车的那一刻**（反向按键 或 松开全部移动键），并支持圈外提前刹车
（正确姿势：滑进圈前就开始急停，让停止点正好落在圈心）。评级用**效率比**：

```
效率比 = 实际急停耗时 ÷ 理论最优耗时(该起停速度下的理想反向点按)
S: ≤1.25× 且 偏移 ≤ 圈的22%   A: ≤1.5× 且 ≤38%   B: ≤1.9× 且 ≤60%   C: 其余
```

这样"急停快慢"与"停点精度"完全解耦——入圈快慢不再影响计时评分；入速过低（<120u/s）不计入。

### 障碍物（左手训练）

左侧面板选择工具后，在场地内**拖动鼠标**绘制：

| 工具 | 操作 | 说明 |
|---|---|---|
| 拉线墙 | 拖一条线（自动吸附横/竖） | 墙厚 24u，两端自动补齐 |
| 矩形块 | 拖一个框 | 最小 40×40u |
| 拆除 | 点击障碍物（或列表 ✕） | 悬停高亮 |

三档高度（**颜色分级**，绘制前选中）：

| 等级 | 颜色 | 高度 | 物理 |
|---|---|---|---|
| 可跨上 | 绿 | 14u | 无需跳跃直接走过去（模拟 CS 台阶 auto-step 18u） |
| 可跳上 | 蓝 | 40u | 空格起跳登顶（跳高 57.6u，需要一定的跳跃时机） |
| 不可跳上 | 红 | 96u | 正面完全阻挡（跳跃也上不去），只能绕行 |

障碍物支持真实碰撞（可沿墙滑行、可跳上跳下、走出边缘会坠落），布局保存在 localStorage；
目标环生成时会自动避开障碍物。急停圈半径可在左侧调节（32–128u，评级阈值按圈比例缩放）。

## 运行

直接双击打开 `index.html` 即可（无构建、无依赖、无网络请求）。
也可用本地服务器：`python -m http.server 8080` 后访问 `http://localhost:8080`。

推荐 Chrome / Edge。页面会申请指针锁定（Pointer Lock）并尝试**原始鼠标输入**（`unadjustedMovement`，跳过系统鼠标加速度，与游戏内一致）。

## 物理实现（CS2 同款算法）

每个物理步固定 `1/128 s`（贴近 CS2 subtick 的平滑度），每步在地面时依次执行：

1. **摩擦**：`drop = max(sv_stopspeed, speed) × sv_friction × dt`，速度按比例衰减；
2. **加速**：`add = min(sv_accelerate × wishspeed × dt, wishspeed − 投影速度)`。

反向急停的机理：按住与速度相反方向键时，加速项与摩擦项**同时**作用，减速约为单纯松键的 2 倍以上——这就是 CS 里“反向键刹车”的手感来源。侧栏会根据当前武器实时数值模拟两者的停止耗时。

有障碍物时，物理层额外执行：轴分离碰撞（沿墙滑行）、台阶高度 18u（CS:GO/CS2 步高，无需跳跃即可跨上）、走出高台边缘自动坠落。

CS2 常量（已验证的官方默认值）：

| 常量 | 值 | 来源 |
|---|---|---|
| sv_accelerate | 5.5 | [Total CS 指令库](https://totalcsgo.com/commands/svaccelerate) |
| sv_friction | 5.2 | [Total CS 指令库](https://totalcsgo.com/commands/svfriction) |
| sv_stopspeed | 80 | [Total CS 指令库](https://totalcsgo.com/commands/svstopspeed) |
| sv_airaccelerate | 12 | [Total CS 指令库](https://totalcsgo.com/commands/svairaccelerate) |
| 重力 / 起跳速度 | 800 u/s² / 302 u/s | Source 引擎标准 |

武器移速表（CS2 实测参考值：[社区测量](https://profilerr.net/de/wie-man-in-cs2-mit-maximaler-geschwindigkeit-l%C3%A4uft/)）：刀/C4 250、手枪 240、沙鹰 230、MP9/MAC10 240、P90/UMP 230、MP7 220、M4A1 225、AK-47/Galil 215、FAMAS/AUG 220、SSG 230、AWP 200（开镜 100）、M249 195、Negev 150。顶栏可选武器以切换移速。

## 灵敏度校准（右手训练）

页面按 CS2 规则映射：`角度 = 0.022 × 灵敏度 × 鼠标计数`，浏览器中 1 像素 ≈ 1 计数。
底栏可调节灵敏度与 DPI（用于换算 360° 鼠标垫距离），请**关闭 Windows「提高指针精确度」**并让游戏内 DPI 与所填 DPI 一致——这样训练时的鼠标手感与游戏完全相同。

## 文件结构

```
index.html          页面骨架（两个训练模块 + 顶栏/侧栏）
css/style.css       深色主题样式
js/config.js        CS2 常量、武器表、设置持久化
js/physics.js       Source 移动物理（摩擦/加速/空中加速/重力）+ 停止耗时模拟
js/left.js          左手急停训练（固定步长物理 + 插值渲染 + 统计评级）
js/aim.js           右手瞄准训练（3D 投影渲染 + 射线命中 + 四种模式）
js/audio.js         WebAudio 合成音效（枪声/命中/脱靶/出球）
js/main.js          标签切换、顶栏控件、全局按键处理
```

## 小提示

- 命中判定为射线近似球体并含**墙面/地面遮挡**（隔墙不能穿怪）。
- 追踪模式小球做正弦游走；反应模式在随机延迟后出球，测的是“出球→命中”的反应时间。
- 60 秒挑战的最佳成绩保存在 `localStorage`。
- 若页面被嵌入 iframe，浏览器会禁用指针锁定——请直接以文件/独立标签页打开。
